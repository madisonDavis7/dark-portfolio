Mission and Idea Behind the Design

I set out to create a company website from scratch to practice creating a professional website while also exploring what a company needs on a site. I knew I wanted the company to reflect my values and decided to focus on green energy.

Tools and Skills

Key Features

Unique Logo

I created a logo that is modern, simple, and reflects the mission of the company.

Sponsors

There is a sponsors section to add to the credibility

Professionalism

The site is clean, has a contact form, and has all information custeomers would need

Solution

I designed a simple, single-page website. The site has a landing section, mission statement, and product information below. It has a modern feel to it and utilizes nature inspired colors to emphasize the company's focus on green enegy. I knew I wanted to add a section with some founders to help create a connection through the site. I wanted it to give off a welcoming and inviting feel.

Learned Along the Way

Because this was my first time tryig to come up with a fake company to base a website on, there was a lot I learned. I did a lot of research on what kinda information a green energy compnay would ahve and tried to make sure it reflected a professional, fully fleshed out site. I put a heavy emphasis on creating a responsive website so I learned quite a lot about using media queries for different sizes, how to utilize the dev tools to test out different devices, and how to have smooth transitions between the various screen sizes.
