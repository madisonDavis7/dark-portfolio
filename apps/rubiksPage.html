Rubiks Cube Simulator

Mission

This project was done for my introductory Java class my second year of college. The goal was not to create a fully functional rubiks cube simulator, instead we were tasked with creating a game where a player input several moves to scramble the cube, and the computer outputs the moves needed to solve the cube. Players were presented with a list of moves, the simulator solved the cube, and the moves used to solve it were output in order.

Tools and Skills

Java Terminal 2D Arrays CLI

Key Features

Terminal Based

The simulator is fully command line based, with the output and structure catered towards the command line

Cube Output

After each turn the cube will be printed out, showing where each cell on the cube is

Valid Moves

Each possible move is accounted for and coded as valid. Users have full control over what moves to make

Solution

Eventhough this project was written in Java, it does not take advantage of OOP. It is a very simple program that has one Cube class and several static methods. The program reads the user input and outputs the opposite move of each, essentially undoing all the moves the user made. Because this was one of my first Java programs it was not written using best practices and has many areas it could be improved upon.

Challenges

The biggest challenge was accurately converting spherical astronomical coordinates into Three.js world space. Small rounding errors caused visible misalignment at the edges of the sphere. Performance was another hurdle — rendering thousands of stars at once required instanced geometry and careful draw-call budgeting to keep frame rates smooth on lower-end hardware.

Learned Along the Way

Because this was one of my first times programming in Java there were a lot of concepts I learned. I got a lot of experience manipulating strings and 2D arrays, whether it was figuring out the cube rotations or printing out the cube sides. A lot of planning went into this project where I learned how to map out what methods I would need, where I need to start, what is necessary to test the project, and how to use debugger tools to make my life easier.
