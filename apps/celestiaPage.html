Celestia

Mission

When I set out to design this app I wanted to create a fun and simple way for children to learn some facts about the planets. The goal was to have the app be interactive and easy to navigate, no matter the age of the user. I wanted to share my love of astronomy and create a learning tool to facilitate that.

Tools and Technology

Ionic Visual Studio JavaScript Firebase ISS API

Key Features

Interactive Planets

Explore our solar system by clicking through the Sun and planets.

Interactive Map

There is an interactive map integrated into the app that let's user see the current location of the ISS.

Solar System Facts

The Sun and it's surrounding planets each have 4 facts listed on their respective pages.

Solution

The web app I created has a minimal design that is both appealing and allows the information to stand out. The design is responsive for all screen sizes, making it more accessible, and works well on tablets. This was intentional and aimed at being a tool for classrooms.

Challenges

The biggest challenge for this app was getting the API integrated and showing correctly. The first API I attempted to use did not end up working so I had to find another free API that would give me the current location of the ISS. After some trial and error I got everything showing and updating correctly.

Learned Along the Way

This was my first time using Ionic and there was a learning curve with using its syntax and structure. This was also my first time researching an API to use and getting it to successfully show on my app. I got experience finding a reliable and safe api, and found some good resources for free, open-sourced apis. I learned a lot about how JavaScript can be used to make HTTP requests to third-party APIs.

This app was created a couple years ago and has been hosted on Firebase since. It is fully functional and interactable.
